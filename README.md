# یادمان (Yadman)

اپلیکیشن یادداشت‌برداری اندروید با Kotlin و Jetpack Compose.

## امکانات
- ساخت، ویرایش و حذف یادداشت
- دسته‌بندی، رنگ کارت و نشان‌کردن (ستاره)
- جستجو و فیلتر بر اساس دسته
- حالت تاریک و مرتب‌سازی از تنظیمات
- ذخیره دائمی روی گوشی (SharedPreferences)
- رابط کاملاً راست‌چین (فارسی)

## اجرا
1. پوشه پروژه را در Android Studio (نسخه Koala یا جدیدتر) باز کنید.
2. صبر کنید Gradle Sync کامل شود (اینترنت لازم است).
3. یک امولاتور یا گوشی وصل کنید و دکمه Run را بزنید.

نیازمندی: JDK 17 (همراه Android Studio هست)، minSdk 24.
